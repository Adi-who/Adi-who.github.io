# Aditya Kumar — Portfolio

Live site: **[adi-who.github.io](https://adi-who.github.io)**

Personal developer site for **Aditya Kumar** ([@Adi-who](https://github.com/Adi-who)).

This branch (`main`) is the production build served by GitHub Pages.

Source code lives on the [`source`](https://github.com/Adi-who/Adi-who.github.io/tree/source) branch.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Motion
- Lucide icons

## Content

Profile copy, socials, and skills come from the public GitHub profile. GitHub stats are fetched live from the GitHub API. Project cards stay empty until public repos exist.
